
# Character to ASCII Value Converter

A beginner-friendly C++ program that takes a character as input and displays its corresponding ASCII value.

## Features

- Accepts a character from the user.
- Converts the character into its integer representation.
- Displays the corresponding ASCII value.
- Allows multiple conversions using a do-while loop.

## Concepts Used

- C++ Basics
- Character Data Type
- Type Conversion
- Input and Output (`cin` and `cout`)
- Do-While Loop
- Conditional Statements

## Technology Used

- Language: C++
- Compiler: GCC (g++)
